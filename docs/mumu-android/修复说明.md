# MuMu Hotfix4 · dev54（2026-10-23）

本版同步纯安卓 hotfix55–70 的适用匹配修复，并保留 Windows + MuMu 的翻译层适配及用户指定的离散搜索策略。仅适用于已验证的 MuMu 6.6.4.0 / Android 12 / 腾讯 38.4.2 环境。

## 主要变化

- 终局时间纳入计分：六塔逐项绝对血差，加超出 ±20 tick 的时间差乘 100；时间不符不算精确。
- 从网页头部读取双方溢出圣水，与引擎累计值及结算 tick ±20 窗口核对。精确匹配沿用截断区间；用户指定额外 0.05 的接受范围单独标为近似，未通过的整局不能播放。
- 移植采集器／镜像首四张禁入及 hotfix65 种子发牌位置解算，不跳过牌序验证；适配精灵女王资料读取。
- 原种子完整建池，仅保留完整执行、顺序、技能身份／实付费用和溢出合格的组合。原种子没有合格项时允许首个合格种子建池。
- 每个后续种子首轮最多模拟 2 组代表，其余延后；最多 3 个种子交错精修，每轮新增 1 组，整场 24 次精修。小空间枚举，大空间先覆盖差异组合再作同费用变异。少量失败不代表整个种子无解。
- 保留历史最佳和未测试组合；进程、资源、准备输入及干净释放证明一致才复用同一任务结果。失败原生任务不自动重发。
- 同步 hotfix70 覆盖搜索、合格精确匹配即停、计分明细与版本提示；显示真实种子数、双方圣水、时间差和技能过程；增加重置回放进程入口。

## 验证与限制

dev54 已覆盖安装，344 项主机检查、72 项设备控制台／状态检查通过，完整 HTML 导入保留 100 条动作、零丢弃。16 组既有原生输出的离线回归确认调用数为 2、1、1；这是离线逻辑验证。

本版没有重新运行整场模拟、完整播放或整场耗时对照，不能声称已测得具体加速倍数。原种子的完整建池和牌序校准仍需时间。作为预发布版交付。

历史 dev48 已完整播放 02JYPPC02YUL：六塔血差 491、终局晚 15.85 秒、网页圣水 14.37/11.66、模拟 14.3718/11.6627，毁塔一致。此记录不能当作 dev54 新搜索策略的整局验收。092PYR8PUC9R 按用户要求未测。

游戏包、签名、库 SHA、架构及网络配置未改；不放宽原生合法性和所有权检查。没有合格整局时不会播放半局。
