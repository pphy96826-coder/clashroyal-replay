# 匹配速度优化 · hotfix67

适用：纯安卓回放 APK，可在 Mac 的 MuMu 模拟器 Pro、兼容的已 Root 安卓系统、兼容的手机安卓虚拟机内部运行。Windows＋MuMu 的翻译适配 APK 不属于本次更新。已包含 hotfix66 的灵魂女皇等级读取修复。

## 优化了什么

1. **筛选与精修不重复预演同一候选。**仅在同一次准备任务内，对完整输入、种子和技能选择完全相同，而且原生组件已确认安全释放的候选，复用其结果与原始证据。最多保留 128 个、总计 8 MiB，超限淘汰，不写入磁盘缓存。
2. **每次复用都重新核对运行身份。**检查游戏进程与映射、公用资源所有者、卡牌目录、工作线程及线程启动时间；读取前后不一致即拒绝。发生客户端恢复或资源身份变化时，不沿用上一代候选缓存。不会复用可调用的原生句柄，也不会重发仍占用现场的任务。
3. **缓存纯计算的合法牌序。**采集器／镜像的合法牌序由完整下牌流和特殊牌位置决定；相同约束不再重复枚举。每个新种子仍进行自己的原生发牌探测、牌序反解和执行核验；已经试过的实体牌组仍会排除，等级等资料仍取本次输入。
4. `seed-search.json` 和种子候选的搜索记录新增复用统计，可检查实际省掉多少重复调用。

这不是减少种子数量或砍掉每个种子的技能枚举。现有搜索预算、原始指令、圣水硬约束、六塔血量／毁塔证据、终局时间校验、JSON 往返核验和发布闸门保持不变。除开局发牌校准外，替代战斗种子搜索仍只按原有猎人／骷髅之王策略启用。

## 验证与性能范围

- 297 项本地自动测试通过，包括新旧枚举结果逐项对照、采集器与镜像同时在卡组、跨进程／资源变化拒绝、缓存限额、失败不复用、筛选与精修一致性等。
- 离线流程对照测试中，同一结果与技能分支所需的预演调用从 5 次降到 3 次。这里的原生执行器是测试替身，不是设备实测。
- Mac 主机的 16 组小型牌序计算基准：原枚举 0.2288 秒，缓存冷启动 0.0960 秒、暖缓存 0.0691 秒，选择结果全部相同。约 2.4～3.3 倍只适用于该纯计算小基准，不能外推为整局匹配速度。
- APK 构建、v2／v3 签名校验通过，与 hotfix66 签名一致。逐项检查内嵌运行文件及校验清单；只有三个相关 Python 文件与清单变化，原生工具和其他依赖不变。
- **未在安卓设备安装或进行完整匹配、播放实测，尚无实际整局耗时对照。**不保证每场都能命中缓存，也不保证搜索能找到原始种子。

## 安装

将 `Android-Replay-20261022-hotfix67.apk` 安装到原来运行控制台与游戏的同一个安卓环境，同签名覆盖即可，不要先卸载或清除数据。版本应显示 `2026.10.22-hotfix67`。设备仍需已有 root 调试能力、项目锁定的腾讯 38.4.2 及完整游戏库哈希匹配。

本次不会自动安装、重启游戏、修改网络或修改游戏 APK。此前失败现场需要按控制台提示处理，不会因为覆盖安装而被静默强制清理。
