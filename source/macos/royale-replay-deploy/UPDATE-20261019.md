# 本次更新

支持合法卡牌/塔楼等级、四种塔楼、国王塔默认等级跟随、初始发牌校准、技能分支有界搜索和塔摧毁证据核验。

队列可以在播放时继续添加HTML并后台解析。诊断包 `*.diagnostic.json` 必须与同名HTML一起放置，只播放已成功执行的前缀，到分歧点暂停，不算整局完成、不写成功缓存。

正常播放结束自动安全释放并重新打开原客户端。直接重建大厅曾崩溃，因此本版不自动使用该路径；当前并非免重启返回。

Mac源码校验和Apple Silicon编译签名已通过；不能据此承诺任意HTML均能精确播放。Windows在单独发布包中保留专用连接层，不得用本Mac包覆盖Windows代码。

安装时若Swift与默认SDK不匹配，指定本机已安装且匹配的SDK：

```sh
python3 scripts/deploy.py install --target /absolute/new/directory --vm-dir /absolute/existing/instance --instance-name 我的安卓-1 --sdk /absolute/path/to/compatible/MacOSX.sdk
```

不改全局Xcode选择、代理、DNS、网络或游戏APK；不创建新模拟器。
