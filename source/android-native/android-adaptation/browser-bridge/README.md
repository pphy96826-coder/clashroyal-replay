# 手机浏览器 → 本机控制台

文件：`royale-replay-phone.user.js`。适用于支持用户脚本管理器的 Android Edge；Chrome 若没有脚本扩展支持，不能只安装本文件就运行。不把桌面 nativeMessaging 扩展当作手机版插件。

1.0.1 将压缩和哈希 API 明确写成 `window.CompressionStream`、`window.crypto`，修正部分篡改猴编辑器对新全局变量的 `no-undef` 警告，不关闭静态检查。如果浏览器实际缺少这些 API，仍明确停止并提示保存完整HTML导入。更新时完整替换原脚本，不粘进默认示例函数；无需重装控制台APK。

## 安装和使用

1. 将支持本桥接的新版「安卓回放控制台」APK覆盖安装到已有设备，保留原有数据。不修改游戏APK、网络或代理。
2. 在手机 Edge 的扩展管理中安装/启用可信的 Tampermonkey（篡改猴）；扩展与站点权限由用户确认。不需要全站、Cookie、历史记录或代理权限。
3. 在篡改猴的「创建新脚本」编辑器里用本目录 `.user.js` 的完整内容替换示例并保存。仅匹配 `https://royaleapi.com/replay?*` 和 `https://www.royaleapi.com/replay?*`；刷新已打开的 Replay 详情页。
4. 在普通 Edge 内自行登录和完成网站验证。完整详情页右下角显示「▶ 在安卓控制台播放」。点它将当前HTML压缩并交给**同一安卓设备**的控制台；不要求电脑服务。
5. 浏览器若拦截异步外部应用跳转，再点面板中「点这里打开控制台」。Android/Edge 的外部应用确认由用户操作，不关闭浏览器安全限制。
6. 控制台核对回放编号、指令数后显示确认页面。点「确认播放本场回放」才调用已有本机播放服务；仍经过完整解析、执行/往返验证、进程/场景归属检查与悬浮进度卡流程。页面脚本不能直接请求 root、执行 shell、重启游戏或跳过确认。

浏览器按钮会尝试一次打开控制台；首次扩展/外部应用许可，以及每次控制台内播放确认，不承诺绕过为“零确认自动播放”。大页面可能超过传输上限，此时明确提示保存完整HTML后用控制台文件选择器导入，绝不删减事件。取消或校验失败不会播放上次文件。

## 数据与安全边界

- 只在按钮点击时取本页DOM，保留全部源字段、时间、方向、形态和技能；移除的只有本脚本自己的浮动面板，避免再次捕获时递归包含传输链接。
- GZIP＋Base64URL 经Android Intent交给锁定包名 `local.royale.replay.android`，无HTTP服务、上传、后台采集、Cookie/密码API或跨浏览器登录复制。
- DOM仍可能包含账户标识或页面token；仅交给本机应用并存入应用私有目录，不能因此称为“没有任何个人数据”。不要把回放传输链接、HTML或私有日志上传/分享。
- 原文上限25MiB、压缩数据160KiB、链接240Ki字符。接收端拒绝重复/未知参数、其他协议/域名、错误标签、损坏压缩包、无效UTF-8、大小超限和SHA256不一致。SHA256验证传输内容完整性，**不认证网页来源**；必须由用户核对并确认播放。
- 不处理网页发来的路径、速度、自动播放、脚本、重启或调试指令；倍率在控制台选。不会更改现有全局延后20tick逻辑。

本目录不包含账号、订阅、Cookie、个人HTML或第三方浏览器安装包。自动化源码/协议测试与真实浏览器安装、跳转、原生可见播放分别验证，不以单测代替端到端验证。

参考：[Android Intent 浏览器限制](https://developer.chrome.com/docs/android/intents)、[Android 深链接输入验证](https://developer.android.com/privacy-and-security/risks/unsafe-use-of-deeplinks)。
